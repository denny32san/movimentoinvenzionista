# Sito Movimento Invenzionista

Sito ufficiale del Movimento Invenzionista.

🌐 Sito live: https://denny32san.github.io/movimentoinvenzionista/

## Descrizione

Questo repository contiene il codice sorgente del sito web del Movimento Invenzionista, pubblicato tramite GitHub Pages.

## Come funziona

Il sito è statico (HTML puro) e viene pubblicato automaticamente tramite Github Pages dal branch `main`.

## Sviluppo locale

Per visualizzare il sito in locale, clona il repository e apri `index.html` nel browser:

```bash
git clone https://github.com/denny32san/movimentoinvenzionista.git
cd movimentoinvenzionista
open index.html
```

## Contribuire

Per proporre modifiche:

1. Fai un fork del repository
2. Crea un branch per la tua modifica (`git checkout -b modifica-x`)
3. Fai commit delle modifiche
4. Apri una Pull Request
